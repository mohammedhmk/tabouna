# صفحة هبوط طابونة

صفحة هبوط لمطعم طابونة (فطاير وبيتزا) — مبنية لتكون وجهة إعلانات (سناب شات وغيره)، سريعة وبدون أي إطار عمل (HTML/CSS/JS خام).

## المعاينة محلياً

```bash
npm run serve
```

يفتح الموقع على `http://localhost:5173`.

## تعديل بيانات المطعم (رقم الجوال، الخريطة، الأوقات...)

كل البيانات القابلة للتعديل موجودة بمكان واحد:
**[assets/js/config.js](assets/js/config.js)**

عدّل القيم داخل `BUSINESS` (الجوال، الواتساب، العنوان، الإحداثيات، ساعات العمل، روابط التواصل) وكل أزرار الصفحة — الاتصال، واتساب، الاتجاهات، الخريطة، وبيانات SEO (JSON-LD) — تتحدّث معاها من مصدر واحد.

> **ملاحظة:** أصناف المنيو والمراجعات (`MENU` و `REVIEWS`) في نفس الملف هي بيانات مرجعية فقط — البطاقات الفعلية مكتوبة داخل [index.html](index.html) (قسم `menu__grid` وقسم `reviews__track`) لأسباب أداء وأرشفة. لتغيير صنف أو صورة أو إضافة مراجعة، عدّلها في `index.html` مباشرة (وحدّث `config.js` بنفس التغيير ليبقى مرجعاً صحيحاً).

## تفعيل بيكسل سناب شات (Snap Pixel)

1. من Snapchat Ads Manager → Events Manager، انسخ الـ Pixel ID
2. الصقه في `SNAP_PIXEL_ID` بأعلى [assets/js/config.js](assets/js/config.js)
3. انشر التحديث (`git push`) — بيكسل سناب يبدأ يشتغل تلقائياً، وإذا تركته فارغاً ما راح يُحمَّل أي شيء (بدون أخطاء)

**الأحداث المرسلة تلقائياً:**

| الإجراء على الصفحة | حدث سناب |
|---|---|
| تحميل الصفحة | `PAGE_VIEW` |
| ضغط أي زر اتصال | `SIGN_UP` + `CUSTOM_EVENT_1` |
| ضغط أي زر واتساب | `START_CHECKOUT` + `CUSTOM_EVENT_2` |
| فتح الاتجاهات / أول ظهور للخريطة | `VIEW_CONTENT` + `CUSTOM_EVENT_3` |

عدّل التعيينات من دالتَي `snap()` و `initPixelTracking()` في [assets/js/app.js](assets/js/app.js) إذا احتجت أحداثاً مختلفة.

## إضافة أو تغيير صور المنتجات

1. ضع الصورة الجديدة (PNG/JPG عالي الجودة) داخل `src/originals/` باسم إنجليزي بسيط
2. أضف سطراً لها في مصفوفة `PHOTOS` داخل [scripts/optimize-images.mjs](scripts/optimize-images.mjs)
3. شغّل:

   ```bash
   npm run images
   ```

   هذا يولّد نسخ WebP بأحجام متعددة داخل `assets/img/` تلقائياً (سريعة وخفيفة)
4. أضف/عدّل بطاقة المنتج في `index.html` (انسخ بطاقة موجودة كقالب)

## النشر (GitHub Pages)

الموقع منشور تلقائياً من فرع `main`. أي تعديل + `git push` يحدّث الموقع المباشر خلال دقيقة أو دقيقتين:

```bash
git add -A
git commit -m "وصف التعديل"
git push
```

الرابط المباشر: **https://mohammedhmk.github.io/tabouna/**

## هيكل المشروع

```
index.html                    الصفحة الرئيسية (كل الأقسام)
assets/css/styles.css         التصميم (الألوان، الزجاج، الاستجابة)
assets/js/config.js           بيانات المطعم + Snap Pixel ← عدّل هنا
assets/js/app.js              الكاروسيل، التتبّع، الخريطة الكسولة
assets/img/                   الصور المُحسّنة (WebP) + الأيقونات
src/originals/                الصور الأصلية عالية الجودة (للتوليد فقط، لا تُستخدم مباشرة بالصفحة)
scripts/optimize-images.mjs   سكربت توليد صور WebP + الشعار الأبيض + الأيقونات
```
